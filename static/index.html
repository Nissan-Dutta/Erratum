Erratum

Nemotron reads the paper. Math checks every number.

Erratum recomputes the statistics, percentages and calculations that a scientific paper reports, and lists any that do not add up. Each item shows the exact sentence it came from, so a person can check it quickly.

What gets checked

Four kinds of number, each recomputed by code. Nothing is flagged unless the paper gives enough information to check it.

P-values

A reported test result and its p-value should agree. Erratum recomputes the p-value from the test statistic and degrees of freedom.

Method: statcheck-style recomputation

Percentages

A percentage should match the counts it is based on. For example, 41 of 64 is 64.1%, not 62.5%.

Method: recomputed from counts

Calculations

A result computed from stated inputs, such as a dose times a body weight, is redone with units. A slip of exactly a factor of 10 is highlighted.

Method: unit-aware arithmetic

Means

An average of whole-number answers, such as a 7-point rating, must be possible for the sample size. Some reported means cannot come from any set of answers.

Method: GRIM test

How it works

  1. Get the paper text

    Erratum fetches the open-access full text from Europe PMC, or uses a section you paste.

  2. Find the numbers

    NVIDIA Nemotron reads the text and lists each checkable number with its exact quote. A quote that is not word-for-word in the paper is discarded.

  3. Recompute

    Code, not a model, does the arithmetic. A number is flagged only when the recomputed value disagrees with the paper. If information is missing, the number is marked not checkable.

  4. Explain, optionally

    Nemotron suggests innocent explanations for each flag, and Tavily reads any preregistration the paper links to. Model suggestions are labeled unverified.

About these flags

Erratum produces automated flags for a person to verify. A flag is not a verdict and not an accusation. It can come from a typo, rounding, an unstated correction, or a test the paper does not describe.

A number that needs information the paper does not give is reported as not checkable, never as a flag. Anything written by a model is labeled unverified.
